# Residential Permit Submittal Checklist — CMPA 4304 Early Prototype

An independent educational **Residential Permit Submittal Checklist** for homeowners and small contractors.

## What works in this early prototype

- Switch between **Window or door replacement** and **Residential addition**.
- View plain-language preparation prompts for each project type.
- Mark items reviewed and see the progress indicator update.
- Clear checkmarks and switch between project types.
- Responsive page that accommodates narrower screens.

This first draft has no backend, user accounts, uploaded building plans, AI review, official approvals, or city-system integration. Checklist text is illustrative and must be verified with current official permitting guidance before any practical use.

## View locally

Open `index.html` with a browser.

## Publish to GitHub Pages

1. Create a new public GitHub repository, e.g. `permitready-capstone`.
2. Upload `index.html` to the repository's root.
3. In repository **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. Copy the live GitHub Pages address after GitHub reports the site is published. Use that actual address in the Canvas discussion post.
